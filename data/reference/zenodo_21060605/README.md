# Contents And Usage

This repository contains the data used for the plots and tables in "*Advanced Scheduling Strategies for Distributed Quantum Computing Jobs*" by G. Ni, D. Ferrari, L. Ho and M. Amoretti.

Data is located in the *data/* directory as log files, a python script to generate the plots can be found in the same directory. The script was tested with **python3.10** and needs **matplotlib** and **numpy** packages. Plots are saved as *.pdf* files in the same directory.

To generate all plots:
```
$ python plot.py
```
